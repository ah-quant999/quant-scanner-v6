## 23:43 卡片时间版式再改：今日/昨日/n天前 HH:MM

### 主人诉求
"改成更新于 今日或昨日或n天前 XX时XX分"（不要 2026-07-16 22:22:36）

### 实现
`fmtCardTime()` 内嵌 `_humanize(v)` 子函数：
- 同一天 → "今日 HH:MM"
- 昨天 → "昨日 HH:MM"
- 2+ 天前 → "n天前 HH:MM"
- 明天 → "明日 HH:MM"
- 未来 → "n天后 HH:MM"
- 解析不出 → 原样回退
- 空 → "未知"

|------|------|

| 2026-07-15 22:22:36 | 昨日 22:22 |
| 2026-07-14 09:40:50 | 2天前 09:40 |
| 2026-07-09 22:22:36 | 7天前 22:22 |
| 2027-01-01 22:22:36 | 169天后 22:22 |
