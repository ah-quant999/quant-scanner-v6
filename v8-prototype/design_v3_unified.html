🌡️温度计算法

综合打分 0~100
= 0.3×涨跌家数比 + 0.2×量能分 + 0.2×北向分 + 0.15×涨停跌停比 + 0.15×情绪分。≥70 偏热，≤30 偏冷。
temp = 0.3*ad_ratio + 0.2*vol_z + 0.2*north_z + 0.15*zt_ratio + 0.15*sentiment

🕸️六维雷达维度

量能 / 情绪 / 资金 / 估值 / 技术 / 外围。各维归一化到 0~100 后绘制多边形。
dims = [vol, sentiment, fund, valuation, tech, external] norm = clip((x - lo)/(hi - lo) * 100, 0, 100)

🌀斐波窗口

以显著高低点为基准日，叠加 5/8/13/21/34/55 交易日序列，标注变盘窗口。与宏观事件（如 FOMC）重合时权重提升。

💰资金流口径
